Description</h2>

<div style="margin-left: 30px; margin-block: 30px">

_ESNTL is a full-stack e-commerce application built with React, TypeScript, Spring Boot, Spring Security, JPA/Hibernate, and MySQL. The application supports product variants, wishlist management, cart and checkout workflows, order management, authentication, role-based authorization, and a switchable local/full-stack data architecture._

Architecture</h2>

                    E-Commerce v2.0
                           │
                           ▼
                  React + TypeScript
                           │
                  ┌────────┴────────┐
                  │                 │
                  ▼                 ▼
             Frontend Mode      Full Stack Mode
                  │                 │
                  ▼                 ▼
          JSON + localStorage   REST API
                                    │
                                    ▼
                              Spring Boot
                                    │
                    ┌───────────────┼───────────────┐
                    │               │               │
                    ▼               ▼               ▼
              Spring Security   Service Layer   Spring Data JPA
                    │                               │
                    ▼                               ▼
                   JWT                           Hibernate
                                                    │
                                                    ▼
                                                  MySQL

NOTE:
_The application supports two data modes: Frontend Mode, which uses local JSON data and browser storage, and Full Stack Mode, which communicates with the Spring Boot REST API and MySQL database._

_A service-layer abstraction keeps the UI independent of the underlying data source, allowing the same frontend components to work with either implementation._

<h2 style="border: 0.1px solid white; font-family: Sail; box-shadow: 0 0 10px white; border-radius: 5px; width: fit-content; padding: 5px 7px; margin-block: 20px">
Key Features</h2>

#### 🛍️ E-Commerce

<li>Product browsing with category/brand-based navigation</li>
<li>Product details with color and size variants</li>
<li>Variant-specific images, SKU and stock availability</li>
<li>Wishlist management</li>
<li>Shopping cart with quantity management</li>
<li>Checkout and order placement</li>
<li>Order confirmation and order history</li>

#### 🔐 Authentication & Authorization

<li>User registration and login</li>
<li>JWT-based authentication</li>
<li>HTTP-only authentication cookies</li>
<li>Protected routes and APIs</li>
<li>Role-based access control (USER, ADMIN)</li>

#### ⚙️ Application Architecture

<li>Frontend Mode using JSON and localStorage</li>
<li>Full Stack Mode using Spring Boot REST APIs and MySQL</li>
<li>Service-layer abstraction for switching between data sources</li>
<li>Persistent cart, wishlist and order data</li>
<li>Responsive React-based UI</li>

#### 🚀 Backend & Data

<li>RESTful API architecture</li>
<li>Spring Data JPA / Hibernate persistence</li>
<li>MySQL database integration</li>
<li>Secure authentication with Spring Security</li>
<li>Independent frontend and backend deployment</li>

Installation</h2>

### Prerequisites

_Make sure you have the following installed:_

<li>Node.js — Frontend</li>
<li>Java 21 — Backend</li>
<li>MySQL — Database</li>
<li>Git — Version control</li>
<br/>

1. Clone the repository:
   ```bash
   git clone https://github.com/Manish-Chatterjee/E-Commerce_v2.0.git
   ```
2. Navigate to the project directory:
   ```bash
   cd E-Commerce_v2.0
   ```
3. Frontend Setup

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. Backend Setup
   ```bash
   cd backend/ecom
   ./mvnw spring-boot:run
   ```
5. Environment Configuration

   _Configure the required environment variables for the frontend and backend before running the full-stack application._

<h2 style="border: 0.1px solid white; font-family: Sail; box-shadow: 0 0 10px white; border-radius: 5px; width: fit-content; padding: 5px 7px; margin-block: 30px">
Environment Variables</h2>

The application uses environment variables to configure the frontend API connection and backend database settings.

<div style="margin-inline: 30px">

### Frontend

Create a .env file in the frontend/root application directory:

```bash
VITE_API_BASE_URL=http://localhost:8080/api
```

### Backend

Configure the database connection and other sensitive settings through environment variables:

```bash
DB_URL=your_database_url
DB_USERNAME=your_database_username
DB_PASSWORD=your_database_password
```

Note: _Never commit .env files or sensitive credentials to the repository._
